

Una lista curada de increíbles recursos, bibliotecas, herramientas y aplicaciones de Pubky. Pubky es un protocolo abierto para backends por clave pública para aplicaciones web resistentes a la censura. 

### Recursos Oficiales
- [pubky.org](https://pubky.org/) - Sitio web del proyecto Pubky
- [docs.pubky.org](https://docs.pubky.org/) - Base de conocimientos de Pubky
- [pubky.app](https://pubky.app/) - Plataforma de aplicaciones Pubky
- [pkdns.net](https://pkdns.net/) - Herramientas de PKDNS
- [pubkyring.app](https://pubkyring.app/) - Aplicación de llavero móvil de Pubky
- [Pubky - The Next Web](https://medium.com/pubky/pubky-the-next-web-3287b35408f1) - Artículo de John Carvalho 

### Servicios
#### Exploradores
- [explorer.pubky.app](https://explorer.pubky.app) - Explorador oficial de Pubky mantenido por el equipo de Pubky
- [pubky.observer](https://pubky.observer) - Mantenido por [aljaz](https://github.com/aljazceru/)
- [pkarr-relay-prod](https://github.com/BitcoinErrorLog/pkarr-relay-prod) - Configuración de despliegue en producción para un relay Pkarr público. Pila de Docker Compose + Caddy + LMDB para conectar clientes HTTP a la DHT Mainline
- [pkarr-mirroring](https://github.com/reisepass/pkarr-mirroring) - Espejo de registros DNS de pkarr desde la DHT Mainline, con clave pública, número de secuencia, firma y datos de paquetes DNS
